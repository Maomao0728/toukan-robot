# 投刊机器人旧版功能审计清单

本清单来自旧版 `C:\Users\Administrator\Desktop\投刊助手源码` 的 Streamlit/Python 代码审计。新版实现前、实现中、验收时都必须逐项对照。

## 页面结构
- 主入口包含 6 个页面：期刊雷达、AI 推荐投稿、我的收藏、投稿记录、投稿模板、资源导入。
- 旧版本地默认无密码；云端配置 `APP_PASSWORD` 时启用密码门。
- 深色科研科技风 UI 需要保留并升级为桌面软件风格。

## 期刊雷达
- 专业频道：计算机、马克思主义、全部学科。
- 英文期刊支持 SCIE/SSCI、评估等级、JIF 分区、中科院分区、影响因子、WOS 发文量、Top/OA、学科、关键词筛选。
- 计算机频道额外支持 CCF 等级、EI 收录、CSCD/北大核心中文刊、CCF 目录。
- 马克思主义频道额外支持 CSSCI、北大核心、AMI 中文刊。
- 收藏所选时重复期刊必须跳过，不重复插入。
- 当前筛选结果可导出 Excel。

## 我的收藏
- 收藏字段：状态、难度、版面费、审稿周期、标签、官网、总结备注、等级、分区、影响因子、学科、出版社、ISSN/eISSN。
- 支持手动添加总表没有的期刊。
- 支持搜索、状态筛选、难度筛选。
- 可直接表格编辑，保存后写入 SQLite。
- 勾选删除后保存才删除。
- 模板列显示该刊是否已有专属模板。
- 可导出收藏库 Excel。

## 投稿记录
- 字段：论文题目、作者、通信作者、期刊、投稿日期、状态、结果日期、版面费、网址、备注经验、创建日期。
- 支持从收藏期刊选择，也支持手动填写期刊。
- 支持搜索、状态筛选、表格编辑、删除、导出 Excel。

## 投稿模板
- 模板目录包含通用模板和按期刊专属模板。
- 支持打开通用模板文件夹和期刊模板文件夹。
- 支持把通用模板复制到期刊专属目录。
- 已存在的模板文件必须跳过，不覆盖。
- 支持下载模板文件。

## 资源导入
- 支持 Excel、CSV、PDF 上传。
- Excel/CSV 预览前 50 行，支持工作表选择。
- 自动识别列名：期刊名称、ISSN、eISSN、影响因子、JIF 分区、中科院分区、学科、出版社。
- 支持 AI 辅助列名识别。
- PDF 第一版只保存原始文件并提示暂未自动解析。
- 确认导入时保存原始文件，并自动备份数据库。

## 论文附件
- AI 推荐页支持 docx/pdf/txt/md 上传。
- 文件保存到论文附件目录。
- txt/md 支持 utf-8-sig、utf-8、gb18030。
- docx 提取段落和表格文本。
- pdf 提取前 30 页文本。
- 扫描 PDF 或空文件提取不到文本时必须提示。
- 长文本生成 AI 节选，优先包含 abstract/introduction/method/conclusion/摘要/引言/方法/结论附近内容。

## AI 推荐
- 题目、摘要、关键词、全文附件任意一项即可推荐。
- 一个信息都没填时禁止推荐。
- 只填 1 项时允许推荐，但必须醒目提示：信息较少，推荐可能不够准确。
- 点击推荐时如果信息较少，再次提示结果仅供初筛。
- 支持投稿目标：期刊类型、目标分区、推荐策略、自定义类型、自定义分区。
- 支持投稿偏好：冲刺、稳妥、好发、中文、英文、SCI、CSSCI、EI、CCF。
- 先从本地候选库筛选，再交给 AI 从候选中选 5 个。
- AI 失败或返回不可解析内容时，必须使用本地规则兜底推荐。
- 推荐结果支持加入收藏，重复收藏跳过。

## AI 接口
- 支持 OpenRouter 和 xFastAPI。
- 页面临时 API Key 优先于配置文件，配置文件优先于 secrets。
- API Key 显示时必须掩码。
- xFastAPI 使用 `/v1/responses`，OpenRouter 使用 `/chat/completions`。
- 必须保留 UTF-8/乱码修复。
- 必须处理 401、模型不支持、524/HTML 超时页、非 JSON、空响应、连接超时。

## 联网补充推荐
- 本地推荐后可手动触发联网搜索更多期刊。
- 搜索来源：Crossref、DuckDuckGo、Bing。
- 联网结果仅作补充，必须提示分区、影响因子、收录情况以官网和数据库为准。
- 任一搜索来源失败不能影响本地推荐。

## 打包和数据保护
- 旧版固定端口 8501，启动时会清理旧投刊助手进程。
- 安装包不会覆盖 journal_library.db、local_config.py、论文附件、资源导入原始文件、数据库备份。
- 新版必须继续保护用户数据，并集中放入 `D:\投刊机器人\data`。
