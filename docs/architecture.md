# 投刊机器人架构说明

新版以 Tauri + Rust + Web 前端实现。旧版源码只读参考，不在新版运行时依赖 Streamlit。

## 硬约束
- 软件名：投刊机器人。
- 主目录：D:\投刊机器人。
- 用户数据目录：D:\投刊机器人\data。
- 代码必须模块化，数据不得散落项目根目录。
- 第一版本地优先，未来预留同步字段和模块。

## 运行策略
- 桌面窗口先出现。
- 数据库、索引、资源扫描后台加载。
- 无网络、无 API Key 时，本地筛选和本地推荐仍可用。

## 索引策略
- SQLite 字段索引用于硬条件筛选。
- SQLite FTS5 用于 BM25/关键词检索。
- embedding 缓存和向量索引放入 data\embeddings 与 data\indexes。
- 用户经验修改后只刷新对应期刊，不全库重建。
