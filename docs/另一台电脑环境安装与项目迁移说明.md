# 投刊机器人另一台电脑环境安装与项目迁移说明

这份文档给后续接手开发的人使用，例如在另一台电脑上让 Claude 继续完善爬虫、RAG、评分和打包工作。

项目主目录建议仍然使用：

`D:\投刊机器人`

## 一、当前项目技术栈

- 桌面框架：Tauri 2
- 后端语言：Rust
- 前端：TypeScript + Vite
- 数据库：SQLite
- RAG / Embedding：Rust `fastembed`
- HTTP 联网：Rust `reqwest`
- 本地数据目录：`D:\投刊机器人\data`

当前这台电脑已验证可用的版本：

- Rust：`rustc 1.97.1`
- Cargo：`cargo 1.97.1`
- Node.js：`v24.18.0`
- npm：`11.16.0`

另一台电脑不一定要完全相同版本，优先安装官网最新版稳定版即可。

## 二、必须安装的软件

### 1. Rust

官网：

<https://www.rust-lang.org/tools/install>

Windows 推荐使用 `rustup-init.exe` 安装。

安装时选择默认配置即可，目标工具链应为：

`stable-x86_64-pc-windows-msvc`

安装后验证：

```powershell
rustc --version
cargo --version
```

### 2. Microsoft C++ Build Tools

官网：

<https://visualstudio.microsoft.com/visual-cpp-build-tools/>

安装 Visual Studio Build Tools 时至少勾选：

- Desktop development with C++
- MSVC v143 或更新版本
- Windows 10/11 SDK
- C++ CMake tools for Windows

Rust Windows MSVC 编译、Tauri、SQLite bundled 构建都需要它。

### 3. Node.js

官网：

<https://nodejs.org/>

建议安装最新版 LTS 或当前稳定版。

安装后验证：

```powershell
node --version
npm --version
```

### 4. Microsoft Edge WebView2 Runtime

官网：

<https://developer.microsoft.com/microsoft-edge/webview2/>

Tauri 桌面窗口依赖 WebView2。Windows 11 通常自带，但另一台电脑如果打不开窗口，需要安装 Evergreen Runtime。

### 5. Git

官网：

<https://git-scm.com/download/win>

如果项目用压缩包复制，可以暂时不用 Git；如果后续要版本管理，建议安装。


绝对不要随意删除：

## 四、迁移到另一台电脑的方法

### 推荐方式

把整个文件夹复制到另一台电脑：

`D:\投刊机器人`

如果另一台电脑没有 D 盘，也可以放在其他路径，但目前代码默认数据目录是：

`D:\投刊机器人`

如果路径改变，需要设置环境变量：

```powershell
$env:TOUKAN_ROBOT_HOME="E:\投刊机器人"
```

或者修改 `crates/core/src/paths.rs` 中的默认路径。

## 五、首次安装依赖

进入前端目录：

```powershell
cd D:\投刊机器人\frontend
npm install
```

回到项目根目录：

```powershell
cd D:\投刊机器人
cargo check --workspace
```

如果 `cargo check` 第一次很慢，是正常的，因为要下载 Rust 依赖并编译。

RAG 的 `fastembed` 首次使用时可能下载 embedding 模型，另一台电脑需要能联网。

## 六、常用开发命令

```powershell

```

### Rust 检查

```powershell

cargo check --workspace
```

### Rust 测试

```powershell

```

### 生成桌面测试 exe

```powershell
cd D:\投刊机器人
cargo build -p toukan-robot-app --features custom-protocol
```

编译完成后的 exe 在：

`D:\投刊机器人\target\debug\toukan-robot-app.exe`

可以复制为：

```powershell
Copy-Item -LiteralPath "D:\投刊机器人\target\debug\toukan-robot-app.exe" -Destination "D:\投刊机器人\投刊机器人.exe" -Force
```

复制前请先关闭正在运行的 `投刊机器人.exe`，否则 Windows 会拒绝覆盖。

## 九、打包前注意事项

用户没有确认前，不要正式打安装包。

正式打包前必须：

1. 备份 `data\db`
2. 前端构建通过
3. `cargo check --workspace` 通过
4. 核心测试通过
5. 双击 `投刊机器人.exe` 能正常启动
6. AI 推荐、本地推荐、RAG、联网补充都能基本使用
7. 安装或更新不能覆盖 `data`

## 十、常见问题

### xFastAPI 返回 529

含义是上游模型服务临时不可用，不一定是 API Key 错。

软件应显示：

`AI 接口暂不可用，已自动切换本地 RAG/规则推荐。`

### API Key 错误

常见是 401 或 403。

### 模型不支持

常见是 404，例如某个账户组不支持指定模型。

### 窗口打不开

优先检查：

- WebView2 Runtime 是否安装
- exe 是否被杀毒软件拦截
- `data\db` 是否损坏

### 构建很慢

第一次构建 Rust、Tauri、fastembed 都可能较慢。后续会快很多。
